A team capstone project at **SAIT**: a web portal for exploring Canadian building retrofit case studies through maps, filters, comparisons, and dashboards.

This overview builds on the project description on [my public GitHub profile](https://github.com/SethiManya). The live application is public; the team source repository remains private.

## My contribution

My role was **frontend development**, contributing to the portal's screens, interactions, and case-study exploration workflow.

The complete portal was developed collaboratively. The application features described here provide project context; my individual role focused on the frontend experience.

## Technologies

**React · TypeScript · Vite · Leaflet · Azure Static Web Apps**

## Project purpose

The portal brings building retrofit case studies into an interface where users can explore examples, narrow their view, and compare information.

| Area | Project context |
| --- | --- |
| Case studies | Explore Canadian building retrofit examples |
| Maps and filters | Navigate and narrow the information displayed |
| Comparisons and dashboards | Review information across case studies |
